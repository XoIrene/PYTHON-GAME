# River Crossing Puzzle Game

A Python-based GUI game built with Tkinter that implements the classic River Crossing Puzzle. The objective is to safely transport a farmer, lion, goat, and maize across a river while following specific constraints:

* The lion cannot be left alone with the goat.
* The goat cannot be left alone with the maize.
* The farmer must operate the boat and can carry only one item at a time.

## Features

* Interactive graphical user interface (GUI) using Tkinter.
* Clickable game elements with emoji representations.
* Move validation based on puzzle rules.
* Undo move functionality.
* Game reset option.
* Win and game-over detection with status updates.

## Technologies Used

* Python 3
* Tkinter GUI Library

This project demonstrates object-oriented programming concepts, event-driven programming, state management, and GUI development in Python.
